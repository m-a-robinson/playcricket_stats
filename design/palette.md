# ELPMCC brand palette (2025)

Source: `ELPM_Website_Colours_2025.pdf` (Coolors export "ELPM Final 6"),
supplied 2026-08-28. Extracted swatch hex values, in the order given on
the sheet:

| Swatch | Hex | Role (as used on the shield / suggested use) |
|---|---|---|
| ![#5B0422](https://via.placeholder.com/12/5B0422/5B0422) | `#5B0422` | Maroon — shield border/background, primary brand colour, headings |
| ![#F4B22F](https://via.placeholder.com/12/F4B22F/F4B22F) | `#F4B22F` | Gold — shield quarters, accents, highlights |
| ![#D1D1D1](https://via.placeholder.com/12/D1D1D1/D1D1D1) | `#D1D1D1` | Light grey — neutral background, rules, card backgrounds |
| ![#9F9F9F](https://via.placeholder.com/12/9F9F9F/9F9F9F) | `#9F9F9F` | Mid grey — secondary text, borders |
| ![#FBE8C0](https://via.placeholder.com/12/FBE8C0/FBE8C0) | `#FBE8C0` | Cream — shield background, warm paper tone |
| ![#084887](https://via.placeholder.com/12/084887/084887) | `#084887` | Navy — secondary brand colour, links/stats accents |
| ![#02111B](https://via.placeholder.com/12/02111B/02111B) | `#02111B` | Near-black — body text, dark backgrounds |

Also see `palette.json` (machine-readable) and `elpmcc.css` (CSS custom
properties) for direct use in templates.
