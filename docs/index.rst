playcricket_stats
===================

A club cricket statistics database that reconciles scorecard data from
six sources (Play-Cricket API, CricHQ PDF archive, CricketStatz ``.MXP``
exports, individual CricketStatz text scorecards, North Manchester
Cricket League season averages, and hand-scored scorebook pages) into
one normalised SQLite store.

This site is the generated **API reference** — each module's own
docstring, rendered. For everything else (how the project is
structured, how to run the example walkthrough, how to maintain the
real database), see the top-level ``README.md``; for the full
development history and the outstanding-issues roadmap, see
``development_notes.md`` and ``ROADMAP.md`` alongside it.
